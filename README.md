## Descripción del sitio
Sitio web informativo para la Feria de Innovación Tecnológica, organizada por una institución de educación superior. Incluye cuatro páginas: Inicio (presentación del evento), Proyectos (seis proyectos tecnológicos simulados), Programa (calendario de actividades) y Contacto e inscripción (formulario visual y datos de contacto).

## Cómo visualizar el sitio
1. Clonar el repositorio: `git clone https://github.com/valentinaarlettarcas-code/Feria-innovacion-tecnologica.git`
2. Abrir el archivo `index.html` directamente en un navegador (doble clic, o `start index.html` desde la terminal en Windows).
3. Navegar entre las páginas usando la barra de navegación superior.

## Tecnologías utilizadas
- HTML5
- CSS3 (hoja de estilos propia en `css/styles.css`, compartida entre las 4 páginas)
- Bootstrap 5 (usado únicamente en la página de Proyectos, para las tarjetas)
